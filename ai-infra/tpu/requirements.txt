# ── TPU Requirements — Llama 3.1 7B Fine-tuning + Inference ──────────────────
# Install: pip install -r requirements_tpu.txt
#
# Hardware: Google Cloud TPU (v3, v4, v5) via Cloud TPU VM
# Must run on a TPU VM — torch_xla does not work on regular CPU/GPU machines
#
# GCP TPU VMs come with torch_xla pre-installed.
# If not, install torch + torch_xla together (versions must match exactly):
#
#   pip install torch==2.3.0 \
#       torch_xla[tpu]==2.3.0 \
#       -f https://storage.googleapis.com/libtpu-releases/index.html
#
# Then install everything else:
#   pip install -r requirements_tpu.txt
#
# NOT supported on TPU (do not install):
#   bitsandbytes  — CUDA-only, no TPU support (no INT4/INT8 quantisation)
#   vllm          — CUDA-only inference server
#   flash-attn    — CUDA kernel, no TPU equivalent
#   nvidia-ml-py  — NVIDIA-specific, meaningless on TPU
# -----------------------------------------------------------------------------
